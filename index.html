Unipolar NRZ

0 = 0 V; 1 = +V. Levels: 0 and +V. No initial level is needed; the signal holds through each bit.

Polar NRZ-L

Assignment convention: 0 = +V; 1 = −V. Levels: +V and −V. Each bit sets its level directly; no initial level is needed.

Polar NRZ-I

0 holds the current level; 1 inverts at the bit boundary. Levels: +V and −V. The selected initial level matters; inverse means a level flip.

Polar RZ

1 = +V then 0 V; 0 = −V then 0 V. Levels: +V, 0, and −V. No initial level is needed; each bit returns to zero.

Polar Biphase Manchester

0 = positive-to-negative mid-bit; 1 = negative-to-positive. Levels: +V and −V. Every bit has a mid-bit transition.

Polar Biphase Differential Manchester

0 inverts at the boundary; 1 does not, then both transition mid-bit. Levels: +V and −V. The initial level matters; inverse means a boundary flip.

Bipolar AMI

0 = 0 V; 1 pulses alternate polarity. Levels: 0, +V, and −V. The first 1 pulse is negative in this implementation.

Bipolar Pseudoternary

1 = 0 V; 0 pulses alternate polarity. Levels: 0, +V, and −V. The first 0 pulse is negative in this implementation.
