How it works

Each cell is one bit period. Voltage is plotted against time: upper is +V, center is 0, lower is −V. A transition means the signal changes level within or between bits.

hi / pos +Vlo / neg −Vinv boundary inversionno inv no inversionRZ return to zeronTp negative → positivepTn positive → negativezero 0 V
